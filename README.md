# Bank Telegram Bot (Multilingual FAQ + Branch Finder)

A Telegram assistant bot for banking customers supporting:
- FAQs in Amharic, Afan Oromo, English
- Branch finder (WebApp integration planned)
- Clean modular architecture (bot + API + services)

## Tech Stack
- Python (FastAPI, python-telegram-bot)
- Database (planned: PostgreSQL)
- WebApp (HTML/JS)

## Setup
1. Create virtual environment
2. Install requirements
3. Copy `.env.example` to `.env` and configure
4. Run bot
